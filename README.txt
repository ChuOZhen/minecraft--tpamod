========================================
TPA Mod - 玩家传送请求模组
========================================

版本: 1.0.0
Minecraft版本: 1.21.11
Fabric Loader: 0.16.10+

========================================
功能介绍
========================================

本模组为服务器添加了玩家间传送请求功能：

1. /tpa <玩家名称> - 请求传送到指定玩家
   - 输入时自动显示在线玩家名称列表
   - 支持Tab键自动补全

2. /tpaccept - 接受传送请求
   - 当有玩家请求传送到你时，使用此命令接受

3. /tpdeny - 拒绝传送请求
   - 拒绝其他玩家的传送请求

4. /tpacancel - 取消自己的传送请求
   - 取消已发送的传送请求

========================================
使用方法
========================================

1. 构建模组：
   - 双击 build.bat 运行构建脚本
   - 等待构建完成

2. 安装模组：
   - 将生成的 build/libs/tpa-1.0.0.jar 复制到服务器的 mods 文件夹
   - 重启服务器

3. 使用命令：
   - 所有玩家都可以使用 /tpa 命令
   - 输入 /tpa 后按Tab键查看在线玩家列表

========================================
命令权限
========================================

所有命令权限等级为 0，意味着：
- 所有玩家（包括非管理员）都可以使用
- 无需OP权限

========================================
传送流程
========================================

1. 玩家A输入: /tpa 玩家B
2. 玩家B收到提示: "玩家A想要传送到你这里"
3. 玩家B输入: /tpaccept (接受) 或 /tpdeny (拒绝)
4. 如果接受，玩家A立即传送到玩家B身边

========================================
注意事项
========================================

- 传送请求60秒后自动过期
- 同一时间只能发送一个传送请求
- 不能传送给自己
- 目标玩家必须在线
